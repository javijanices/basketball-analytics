# 🏀 Basketball Analytics Platform

Proyecto de análisis de estadísticas de básquet desarrollado en Python.

## Tecnologías

- Python
- CSV
- Git
- GitHub

## Funcionalidades

- Lectura de estadísticas desde CSV
- Cálculo de puntos totales
- Promedio del equipo
- Máximo anotador
- Procesamiento de datos
